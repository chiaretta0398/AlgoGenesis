Modulo 1: Fondamenti dell'Intelligenza Artificiale

L'Intelligenza Artificiale (IA) è il ramo dell'informatica che sviluppa sistemi in grado di svolgere compiti che richiederebbero l'intelligenza umana (ragionamento, apprendimento, risoluzione di problemi).


1.1 AI vs Machine Learning vs Deep Learning

  • AI (Intelligenza Artificiale): Il concetto macroscopico di macchine "intelligenti".
  • Machine Learning (ML): Sottoinsieme dell'IA in cui gli algoritmi imparano dai dati invece di essere programmati con regole fisse.
  • Deep Learning (DL): Sottoinsieme del ML basato su Reti Neurali Artificiali a più strati.

Modulo 2: Python per sviluppatori AI

Python è il linguaggio standard per l'IA grazie alle sue librerie essenziali come NumPy, Pandas, e PyTorch.

# Esempio Python: La tua prima Rete Neurale Concettuale
def neurone(input_dato, peso, bias):
    attivazione = (input_dato * peso) + bias
    return 1 if attivazione > 0 else 0

print("Output del neurone:", neurone(0.8, 1.5, -0.5))

Modulo 3: Reti Neurali e Machine Learning

Un modello di Machine Learning apprende regolando i suoi pesi (weights) e bias durante una fase chiamata Addestramento (Training), riducendo l'errore calcolato da una Loss Function.

Cos'è il Machine Learning?
È una branca dell'IA in cui i computer imparano a riconoscere pattern e prendere decisioni analizzando grandi quantità di dati, senza istruzioni esplicite.
A cosa serve la Loss Function?
Misura la distanza (l'errore) tra la previsione fatta dal modello IA e il valore reale desiderato.
Qual è la funzione del Bias?
È un valore aggiunto al calcolo del neurone per consentire al modello di adattarsi meglio e spostare l'attivazione a destra o sinistra.
