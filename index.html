Modulo 1: Le Basi dell'Intelligenza Artificiale e del Machine Learning

1.1 Cos'è davvero l'Intelligenza Artificiale?

L'Intelligenza Artificiale (IA) è la disciplina dell'informatica che crea sistemi capaci di svolgere compiti complessi che richiederebbero facoltà cognitive umane: comprensione del linguaggio, riconoscimento visivo, pianificazione e risoluzione di problemi.

Il Cambio di Paradigma:
• Programmazione Tradizionale: Dati + Regole (Codice scritto a mano) ➔ Risultati.
• Machine Learning (ML): Dati + Risultati Desiderati ➔ L'algoritmo impara le Regole da solo.

1.2 I Tre Pilastri del Machine Learning

  • Supervised Learning (Apprendimento Supervisionato): Il modello impara da dati "etichettati" (es. immagini contrassegnate come "Gatto" o "Cane"). Si divide in:
    • Classificazione: Prevedere categorie discrete (Spam / Non Spam).
    • Regressione: Prevedere valori continui (Prezzo di una casa in base alla metratura).
  • Unsupervised Learning (Non Supervisionato): L'algoritmo analizza dati non etichettati per trovare pattern o gruppi nascosti (es. Clustering per segmentare i clienti di un e-commerce).
  • Reinforcement Learning (Apprendimento per Rinforzo): Un agente software impara interagendo con un ambiente, ricevendo ricompense per azioni corrette e penalità per errori (usato nei sistemi di guida autonoma o videogiochi).

1.3 Etica e Bias nei Dati

Gli algoritmi di IA non sono intrinsecamente "neutrali": imparano dai dati storici. Se i dati contengono pregiudizi o disparità (i cosiddetti bias), il modello di Machine Learning tenderà a replicarli e amplificarli. Il ruolo dello sviluppatore AI include la pulizia e la valutazione etica del dataset.

Modulo 2: Matematica essenziale e Python per l'IA

2.1 Perché Python?

Python è diventato lo standard de facto dell'IA grazie alla sua sintassi pulita e ad un ricco ecosistema di librerie scientifiche.

2.2 Le Librerie Fondamentali: NumPy e Pandas

NumPy: Fornisce la struttura dati ndarray per eseguire calcoli vettoriali rapidi ad altissima velocità.

Pandas: Introduce il DataFrame, una struttura a tabella ideale per la pulizia, l'analisi e la trasformazione dei dati prima del training.

import numpy as np
import pandas as pd

# Creazione di un array di input per un modello
X = np.array([[1.0, 2.5], [3.0, 4.1], [5.2, 1.8]])

# Definizione dei Pesi (Weights) e Bias
weights = np.array([0.4, -0.6])
bias = 0.1

# Calcolo del prodotto scalare (Dot Product)
previsione = np.dot(X, weights) + bias
print("Output del calcolo matriciale:", previsione)

2.3 Le Basi Matematiche: Vettori, Matrici e Gradient Descent

Ogni modello di ML converte le informazioni (immagini, testi, suoni) in vettori numerici. Il processo di apprendimento ottimizza questi numeri tramite il Gradient Descent (Discesa del Gradiente), un algoritmo di calcolo infinitesimale che trova i valori ideali dei pesi riducendo gradualmente l'errore.

Modulo 3: Reti Neurali e Deep Learning Fondamentale

3.1 Anatomia del Perceptron (Il Neurone Artificiale)

La rete neurale artificiale trae ispirazione dalla struttura biologica del cervello. L'unità fondamentale è il Perceptron:

Formula Matematica dell'Output:
y = Funzione_di_Attivazione( (Input_1 * W1 + Input_2 * W2 + ...) + Bias )

3.2 Le Funzioni di Attivazione

Introducono la non-linearità, consentendo alla rete di imparare concetti complessi:

  • ReLU (Rectified Linear Unit): Trasforma tutti i valori negativi in 0. È la più utilizzata negli strati nascosti.
  • Sigmoid: Comprime i valori tra 0 e 1 (ideale per la classificazione binaria).
  • Softmax: Trasforma i valori in un insieme di probabilità la cui somma è 1 (classificazione multi-classe).

3.3 Il Ciclo di Addestramento (Training Loop)

  1. Forward Propagation: I dati attraversano la rete dall'input all'output generato.
  2. Calcolo della Loss Function (Funzione di Perdita): Calcola la differenza precisa tra l'output predetto dal modello e il dato reale.
  3. Backpropagation: L'errore viene propagato all'indietro usando la regola della catena del calcolo differenziale.
  4. Aggiornamento Pesi: Gli ottimizzatori (es. Adam, SGD) modificano i pesi per migliorare la risposta al ciclo successivo.

Modulo 4: Progetti Pratici e Framework di Produzione

4.1 I Framework di riferimento: PyTorch e TensorFlow

Per costruire modelli complessi senza riscrivere le equazioni matematiche da zero, gli AI Developer utilizzano framework ad alte prestazioni come PyTorch (sviluppato da Meta) e TensorFlow / Keras (sviluppato da Google).

4.2 Esempio Pratico in PyTorch: Una Rete Neurale Completa

import torch
import torch.nn as nn

# Definizione della struttura dell'architettura neurale
class AlgoGenesisModel(nn.Module):
    def __init__(self):
        super(AlgoGenesisModel, self).__init__()
        self.strato_ingresso = nn.Linear(in_features=10, out_features=64)
        self.relu = nn.ReLU()
        self.strato_uscita = nn.Linear(in_features=64, out_features=1)
        
    def forward(self, x):
        x = self.strato_ingresso(x)
        x = self.relu(x)
        x = self.strato_uscita(x)
        return x

# Istanza del modello
modello = AlgoGenesisModel()
print("Architettura della Rete Neurale AlgoGenesis:")
print(modello)

4.3 Overfitting e Deployment

Uno dei problemi principali del Machine Learning è l'Overfitting (quando il modello impara a memoria i dati di addestramento ma fallisce sui dati nuovi). Si previene usando tecniche di Dropout, Regularization e dividendo il dataset in set di Training e Validation.

Una volta addestrato e validato, il modello viene distribuito (deployment) tramite API web per essere integrato all'interno di applicazioni interattive o app aziendali.

Flashcards di Ripasso Rapido

Tocca una carta per girarla e verificare la spiegazione teorica.

Supervised vs Unsupervised Learning
Il Supervised usa dati etichettati (input + risposta corretta). L'Unsupervised lavora su dati grezzi per scoprire pattern o raggruppamenti automatici.
Cos'è il Gradient Descent?
È l'algoritmo di ottimizzazione matematica che calcola la direzione in cui modificare i pesi per ridurre al minimo l'errore (Loss).
Ruolo del Dropout
Disattiva casualmente una percentuale di neuroni durante l'addestramento per evitare l'overfitting e rendere il modello più robusto.
A cosa serve la ReLU?
La ReLU è una funzione di attivazione che azzera i valori negativi. Aggiunge non-linearità con una grande efficienza computazionale.
